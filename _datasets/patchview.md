### Overview
A dataset of code modifications, commit messages, and repository metadata used to evaluate models for security patch identification.

### Details
* AST-level code representations of changes.
* Commit message text.
* Repository-level activity metadata from version control.
* Accompanies the paper *"PatchView: Multi-modality detection of security patches"* in *Computers & Security* (2025).
