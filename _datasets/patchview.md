### Overview
PatchView is a multi-modal dataset designed to train and benchmark machine learning models for detecting software security patches. It captures structural AST representations of code modifications, commit messages, and repository-level developer interaction dynamics.

### Dataset Features
* Multi-modal feature representations (AST diffs, natural language commit logs, developer metadata).
* Balanced benchmark partitions for security vs. non-security patch classification.
* Accompanies the paper *"PatchView: Multi-modality detection of security patches"* published in *Computers & Security* (2025).
