## Overview

Keystroke dynamics are often used as a behavioral biometric to verify users based on typing rhythms. This paper examines an attack using a modified USB keyboard that learns a user's typing patterns to bypass biometric verification. We also present a detection framework that uses acoustic emissions and USB communication timing to distinguish authentic user keystrokes from automated hardware injections.
